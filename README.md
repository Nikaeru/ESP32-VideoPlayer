# ESP32 Video Player

Веб-плеер для компактной платы **ESP32-C3 с OLED-дисплеем 0,42″ 72×40**. Плата создаёт собственную Wi-Fi-сеть, принимает видео через встроенную веб-страницу, сохраняет его в LittleFS и воспроизводит на OLED без подключения к интернету.

MP4 декодируется и преобразуется в браузере. На ESP32 отправляется готовый монохромный поток кадров размером 72×40 пикселей.

## Возможности

- автономная точка доступа и веб-интерфейс;
- выбор фрагмента исходного видео;
- частота кадров от 5 до 40 FPS;
- обрезка, вписывание с полями или растягивание кадра;
- настройка порога чёрного/белого и инверсия изображения;
- предпросмотр результата в браузере;
- параллельная конвертация и пакетная отправка по 32 кадра;
- Play, Pause, Restart и удаление сохранённого видео;
- изменение скорости воспроизведения от 0,25× до 2×;
- автоматический запуск и циклическое воспроизведение после загрузки или перезагрузки;
- проверка формата и размера файла перед его активацией.

## Поддерживаемое оборудование

- ESP32-C3, 4 МБ Flash;
- OLED 72×40 с контроллером SSD1306;
- I²C-адрес дисплея: `0x3C`;
- SDA: `GPIO5`;
- SCL: `GPIO6`.

Конфигурация PlatformIO использует плату `esp32-c3-devkitm-1`. Для другой ревизии платы может потребоваться изменить модель дисплея или GPIO в `src/main.cpp`.

## Сборка и загрузка

Необходимы [Visual Studio Code](https://code.visualstudio.com/) с PlatformIO либо установленный PlatformIO Core.

```powershell
cd ESP32-VideoPlayer
pio run
pio run -t upload --upload-port COM6
```

Замените `COM6` на порт своей платы. Serial Monitor работает на скорости 115200 бод:

```powershell
pio device monitor -b 115200
```

Команда `uploadfs` не требуется: видео загружается через веб-интерфейс.

## Использование

1. Включите плату и подключитесь к сети:

   - SSID: `VideoPlayer-ESP32`
   - пароль: `videoplay32`

2. Откройте в Chrome или Edge адрес [http://192.168.4.1](http://192.168.4.1).
3. Выберите MP4-файл, начало и конец фрагмента.
4. Настройте FPS, масштабирование и порог яркости.
5. Нажмите **«Преобразовать и загрузить»**.
6. После проверки файла воспроизведение начнётся автоматически.

Во время конвертации держите вкладку открытой и активной. Фоновые вкладки ограничиваются браузером и обрабатывают кадры медленнее.

## Как это работает

```text
MP4 в браузере
      ↓
HTMLVideoElement + Canvas, 72×40, 1 бит на пиксель
      ↓
пакеты по 32 кадра через HTTP
      ↓
временный файл /video.tmp в LittleFS
      ↓ проверка размера и заголовка
/video.bap
      ↓
OLED SSD1306
```

Один кадр занимает `72 × 40 / 8 = 360` байт. Пользовательский раздел LittleFS имеет размер около 2,88 МиБ, из которых 64 КиБ зарезервированы. Точный допустимый размер рассчитывается платой и отображается на странице.

### Формат BAP1

Файл начинается с 16-байтового заголовка:

| Смещение | Размер | Поле |
|---:|---:|---|
| 0 | 4 | сигнатура `BAP1` |
| 4 | 1 | версия формата |
| 5 | 1 | ширина, 72 |
| 6 | 1 | высота, 40 |
| 7 | 1 | FPS |
| 8 | 4 | количество кадров, little-endian |
| 12 | 4 | размер данных, little-endian |

После заголовка идут кадры по 360 байт, строки упакованы в формате MSB-first.

## HTTP API

| Метод | Адрес | Назначение |
|---|---|---|
| `GET` | `/` | веб-интерфейс |
| `GET` | `/api/status` | состояние плеера и памяти |
| `POST` | `/api/upload/start` | начало пакетной загрузки |
| `POST` | `/api/upload/chunk` | отправка группы кадров |
| `POST` | `/api/upload/finish` | проверка и активация файла |
| `POST` | `/api/upload/cancel` | отмена загрузки |
| `POST` | `/api/play` | продолжить воспроизведение |
| `POST` | `/api/pause` | пауза |
| `POST` | `/api/restart` | начать сначала |
| `POST` | `/api/speed` | изменить скорость, параметр `value` |
| `DELETE` | `/api/video` | удалить видео |

## Ограничения

- Рекомендуются современные Chrome и Edge.
- Скорость конвертации зависит от кодека, процессора.
- ESP32 не декодирует MP4 самостоятельно.
- Звук не поддерживается.
- При начале новой загрузки предыдущее видео удаляется.
- При слишком большом файле необходимо сократить фрагмент или уменьшить FPS.

## Решение проблем

- **Страница не открывается:** убедитесь, что устройство подключено к `VideoPlayer-ESP32`, и введите адрес с `http://`, а не `https://`.
- **COM-порт занят:** закройте Serial Monitor перед загрузкой прошивки.
- **Браузер не открывает видео:** используйте MP4 с кодеком H.264, поддерживаемым Chrome/Edge.
- **Видео не помещается:** уменьшите длительность или FPS; рассчитанный размер показывается до загрузки.
- **Экран пустой:** проверьте I²C-адрес `0x3C`, SDA `GPIO5`, SCL `GPIO6` и модель OLED.
